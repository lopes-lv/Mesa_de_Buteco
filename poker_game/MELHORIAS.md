# Backlog de Melhorias do Projeto

Este documento armazena todas as ideias, melhorias e novas funcionalidades planejadas para o futuro do jogo.

## 1. Melhorar o Design Geral do Jogo
- Atualizar a estética do menu principal, mesa, botões e telas finais.
- Tornar a interface mais polida e moderna, mantendo ou melhorando o estilo desejado.

## 2. Sistema de Seleção de Baralhos
- Criar um menu ou tela nas configurações para permitir que o jogador escolha qual baralho deseja usar na partida.
- Suporte a múltiplos modelos de baralhos, cada um com seus próprios assets e desenhos.

## 3. Ajustes no Desenho do Baralho Atual
- Refinar, consertar ou melhorar a arte do baralho (naipes, números, rostos de J, Q, K e verso).

## 4. Ferramenta de Criação de Baralhos (Modo Admin/Editor)
- Criar uma seção especial (voltada para o administrador ou criador).
- Permitir a criação de novos designs de cartas de forma visual ou guiada.
- Possibilidade de "montar" e salvar um baralho personalizado a partir dos assets criados para ser usado no jogo.

## 5. Novos Modos de Jogo
- Expandir além do Texas Hold'em.
- Implementar o modo de jogo **Pif Paf**.
- Implementar e projetar um modo de jogo inédito/diferente.
## 6. Documentação do Projeto
- Escrever um **GDD (Game Design Document)** para consolidar todas as mecânicas, regras e visão do jogo em um único lugar.
- Escrever um **Guia de Estilo** (Style Guide) contendo as diretrizes da pixel art, paleta de cores e identidade visual do projeto.
